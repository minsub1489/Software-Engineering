# HumanProof 크롬 확장 팝업 시연 가이드

크롬 브라우저처럼 보이는 화면 안에서 확장 프로그램의 사용 흐름을 보여주는 클릭 프로토타입입니다. 실제 확장 프로그램 설치나 기능 구현 없이 팀 프로젝트를 설명하기 위한 화면 모형입니다.

## 실행

`HumanProof_크롬확장_프로토타입.html`을 Chrome 또는 Edge에서 엽니다. CSS와 JavaScript가 파일 안에 포함되어 있어 인터넷이나 패키지 설치가 필요하지 않습니다.

처음에는 팝업이 열려 있습니다. 오른쪽 위 보라색 방패 아이콘 또는 팝업의 닫기 버튼으로 닫았다가 방패 아이콘을 눌러 다시 열 수 있습니다. 팝업을 닫아도 현재 장면은 유지됩니다. 화면이 짧으면 팝업 안을 스크롤하세요.

## 2분 시연

| 장면 | 클릭 순서 | 발표 멘트 |
| --- | --- | --- |
| 확장 팝업 | 팝업 닫기 → 보라색 방패 아이콘 | “AI를 사용하는 페이지에서 바로 HumanProof를 열 수 있습니다.” |
| 작업 등록 | 시연용 PDF 선택 → AI 활용 범위 → 작업 등록 | “AI 작업의 결과물과 활용 범위를 연결합니다.” |
| 이해 확인 | 각 질문에서 샘플 답변 넣기 → 답변 제출 | “선택 이유를 설명하고, 오류를 찾고, 조건 변경의 영향을 확인합니다.” |
| 검토 | 검토자 B 선택 → 체크리스트 세 항목 → v1 승인 | “다른 검토자가 작성자의 이해 확인 답변과 결과물을 검토합니다.” |
| 증명서 | 승인된 원본 → 수정된 파일 | “승인 기록은 특정 파일 버전에 연결됩니다. 수정된 파일은 다시 검토해야 합니다.” |

화면 아래 `01 등록`, `02 이해 확인`, `03 검토`, `04 증명서` 버튼은 샘플 상태를 준비해 해당 장면으로 바로 이동합니다. 발표 시간이 짧을 때 이용하세요. 오른쪽 위 `시연 처음부터`로 초기화합니다. 새로고침하면 모든 답변과 시연 상태가 초기화됩니다.

## 화면 모형의 범위

- 브라우저 주소와 AI 대화는 고정된 배경 예시입니다.
- PDF 연결은 샘플 파일 선택 장면입니다. 실제 파일을 읽거나 업로드하지 않습니다.
- 역할, 이해 과제, 검토 체크리스트와 증명서는 시연용 상태입니다.
- 파일 식별값과 원본·수정 파일의 비교 결과는 예시입니다. 해시 계산, 전자서명이나 실제 인증을 수행하지 않습니다.
- 확장 프로그램 API, 계정 인증, AI 호출, 서버와 저장소는 연결하지 않았습니다.

기존 `HumanProof_프로토타입.html`과 `dist/`는 별도의 웹 프로토타입입니다. 이번 확장 팝업 모형의 스타일, 샘플 문항과 클릭 동작은 `HumanProof_크롬확장_프로토타입.html`에서 수정합니다.
