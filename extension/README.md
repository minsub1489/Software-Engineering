# HumanProof Chrome 기여 기록 확장

저장소에 기존 확장 구현이 없어 새로 추가한 로컬 MVP입니다. 웹 프로토타입과 연결되는 JSON 기록 도구이며, 서버 계정·전자서명·AI 사용 자동 탐지를 제공하지 않습니다.

## 설치와 사용

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. 저장소의 `extension` 폴더를 선택하고 HumanProof 아이콘을 고정합니다.
4. 근거로 사용할 일반 웹페이지에서 확장 아이콘을 클릭합니다. 원하는 경우 텍스트를 먼저 선택합니다.
5. 팝업에서 **현재 페이지 정보 가져오기**를 누릅니다. 선택 텍스트도 필요하면 먼저 해당 체크박스를 켭니다.
6. 기여 유형·단계·작업 설명과 페이지 정보의 개인정보를 확인한 뒤 **확인한 기록 저장**을 누릅니다.
7. **JSON 내보내기**로 다운로드합니다. HumanProof의 **버전 · 이력 → 확장 기여 기록 가져오기**에서 파일을 선택하고 미리보기를 확인한 뒤 연결합니다.

기록은 현재 버전의 검토 범위에 포함됩니다. 가져오면 이전 평가·체크리스트가 초기화되므로 검토자가 다시 확인해야 합니다. 승인된 버전에는 추가할 수 없으며 새 버전을 만든 뒤 연결해야 합니다. 같은 기록 ID는 한 번만 추가합니다.

## 권한과 데이터

- Manifest V3. `activeTab`·`scripting`·`storage`만 사용합니다. 페이지 수집은 확장 아이콘과 가져오기 버튼을 누른 뒤 실행됩니다.
- 기본은 제목과 URL만 가져옵니다. 선택 텍스트는 별도 선택 시에만 읽으며 문서 전체·쿠키·비밀번호 필드를 읽지 않습니다.
- URL의 query와 fragment를 제거합니다. 경로·제목·선택 텍스트에 남은 정보는 저장 전에 사용자가 삭제해야 합니다.
- Chrome 로컬 저장소에 최대 100개를 저장합니다. 설명은 2,000자, 선택 텍스트는 5,000자까지입니다.
- 서버 전송과 sync 저장을 사용하지 않습니다. JSON에는 직접 기록한 정보가 담기므로 공유 전 내용을 확인하세요.
- 전체 삭제는 내보낸 파일을 확인했다는 체크 이후에 가능합니다. 확장 제거는 로컬 기록을 지우므로 먼저 내보내세요.

## 실제 설치 후 점검

1. 일반 HTTPS 페이지에서 아이콘 클릭 → 제목·주소 수집 → 저장 → 팝업 닫기/재열기 후 기록 유지.
2. 텍스트 수집 체크 OFF에서는 선택 영역이 있어도 읽지 않음. ON에서 5,000자 초과 선택 시 안내.
3. `chrome://settings`, Chrome 웹스토어, 로컬 PDF/파일에서는 접근 불가 안내.
4. SPA 이동·다른 사이트 이동 후 재수집. 페이지 이동 도중에는 다시 가져오기 안내.
5. 두 창에서 기록을 저장해도 기존 기록이 사라지지 않음. 저장 실패 시 성공 메시지를 표시하지 않음.
6. 악의적인 HTML 문자열이 텍스트로만 표시됨. `javascript:` 주소·자격정보 포함 URL 거부.
7. JSON 내보내기 → 웹 미리보기 → 확인 연결 → 중복 가져오기 차단 → 평가 초기화.

`node --test tests/*.test.cjs`는 데이터 규칙과 Manifest 권한을 검사합니다. 팝업 모의 API 테스트는 `tests/extension-browser.cjs`에 있습니다. 실제 툴바 클릭으로 활성화되는 activeTab 권한은 수동 점검이 필요합니다.
